# 造物主：孤岛

运行在 FoloToy AI Passport 上的上帝视角孤岛模拟。岛民自己找吃的、盖房、种田、交友、成家、生儿育女、老去；你用三个按键观察他们，或者降下神力。把它放下不管，岛上的日子照常过，回来时它会告诉你发生了什么。

## 目录

```
main/      固件源码（放进官方仓库的 main/ 目录）
  sim.c         模拟核心（一）：寻路、居民的需求与状态机、社交与家庭
  sim_world.c   模拟核心（二）：地图生成、生态、天气、灾害、世代更替、神力
  sim.h / sim_int.h
  render.c/h    渲染器：把世界画进三块 RGB565 帧缓冲
  sfx.c/h       音效合成、麦克风拍手 / 吹气识别（纯计算）
  game.c/h      游戏层：按键、时间推进、离线补算、息屏休眠、自动存档
  main.c        设备入口：官方 BSP（屏幕、按键、音频、电量计）+ LVGL + NVS + 深度休眠
  font_data.c   12px 点阵字库（自动生成）
host/      主机端测试台（只需要 gcc）
tools/     gen_font.py：字库生成脚本
docs/      DESIGN.md：可行性分析、架构、数据结构、模拟机制；screenshots/
build.sh   本机编译脚本
.github/   GitHub 自动编译
```

## 获取 .bin 固件

固件要用 ESP-IDF 编译才能得到。三种办法，任选其一：

**办法一：让 GitHub 替你编译（不用装任何东西）**

1. 在 GitHub 新建一个仓库，把本工程整个上传（包括 `.github` 文件夹）。
2. 打开仓库的 Actions 页，等 "Build firmware" 跑完（约 5～10 分钟）。
3. 在这次运行的页面底部下载 `island-firmware`，解压后里面的 `island-full.bin` 就是完整固件。

**办法二：本机一条命令**（需要 git，以及 Docker 或已安装的 ESP-IDF 5.5.x）

```bash
./build.sh        # 产出 dist/island-full.bin
```

**办法三：手动**

```bash
git clone https://github.com/FoloToy/ai-passport.git
cd ai-passport
git switch -c feature/island-god-game
rm -f main/*.c main/*.h main/CMakeLists.txt      # 保留 main/idf_component.yml（如果有）
cp /path/to/island/main/* main/
idf.py set-target esp32c3
idf.py build
idf.py merge-bin -o island-full.bin               # 在 build/ 目录下
```

## 烧录

```bash
# 整片烧录合并固件（会清掉设备上原有的存档）
python -m esptool --chip esp32c3 -p <串口> write_flash 0x0 island-full.bin

# 或者在工程目录里分段烧录（保留存档）
idf.py -p <串口> flash monitor
```

启动日志里会打印一行 `free heap ... largest block ...`，第一次上机请留意这个数字（见下文"尚未验证"）。

## 操作

| 按键 | 平时 | 观察居民时 | 家谱页 |
| --- | --- | --- | --- |
| 上 / 下 | 切换神力 | 切换居民 | 选择一位亲属 |
| 长按上 | 跳到上一类神力 | **赐福此人**（治愈、吃饱、精神焕发） | 同上 |
| 长按下 | 跳到下一类神力 | **降罚此人**（一道雷劈在他头上） | 同上 |
| 确认 | 施放当前神力 | 返回 | 转到这位亲属的家谱 |
| 长按确认 | 暂停 / 继续（暂停时立即存档） | 返回 | 返回岛屿 |

息屏时第一下按键只负责点亮屏幕。施放神力时屏幕中央会打出大字。观察居民时镜头会拉近两倍跟着他走。

神力共 37 项，分六类：

| 类别 | 内容 |
| --- | --- |
| 观察 | 观察居民、家谱、岛屿纪事（逝者、新生、信仰与恐惧） |
| 创造 | 降下森林、创造野猪、创造兔子、放出恶狼、召来鱼群、赐予食物、创造居民、**降下先民**（一次五位）、创造矿石、创造水源、创造庄稼 |
| 祝福 | 治愈众生、万物生长、平息灾祸、**消灭狼群**、**清除乱石**（所有碎石化为草地；没有碎石时削平离营地最近的一截山）、**复原大地** |
| 天气 | 晴天、阴天、小雨、暴雨、雷电、大风、暴风雪、流星雨、彩虹、日食 |
| 灾害 | 天降雷火、森林大火、洪水、地震、火山喷发、瘟疫 |
| 设置 | 时间流速（1 / 2 / 8 / 32 倍）、音效开关、声控神力开关、镜头（全岛 / 近景）、**重造新岛** |

天气：大自然自己会变天，多数时候晴、阴、小雨、刮风；偶尔有短暂的暴雨、雷电（冬天是风雪），威力只有神降的一半，自然的雷只会点着劈中的那棵树。火山、地震、瘟疫、洪水、恶狼这些大灾，只有你动手才会发生。

时间：1 倍速下现实 **5 分钟** = 游戏 1 天，4 天为 1 年，每天一个季节（春夏秋冬）。速度档 1 / 2 / 8 / 32 倍。居民 60 岁起每天有概率老死，多数活到 60～66 岁。每 3 分钟自动存档一次。

## 四季、时代、建筑、职业

- **四季**：一年四天，每天一季。春天开花、庄稼长得快、野兽繁殖多；夏天浆果多；秋天树叶变黄变红、收成加倍；冬天下雪结冰，庄稼不长，夜里在屋外会冻伤，鱼也少。没有粮仓时，每换一季仓里的粮食坏掉一成。
- **时代**：石器 → 青铜 → 铁器 → 航海。人口、房屋、石料、手艺够了，就会有人摸索出新本事。时代越新，干活越快、产出越多；工具、衣服、房子的样子也会变（石器时代穿兽皮，铁器时代盖石屋）。岛上的人死光后重新开始，手艺失传，回到石器时代。
- **新建筑**：岛民自己决定修什么。水井（附近的火更容易扑灭，庄稼长得快）、粮仓（粮食不再坏）、码头和渔船（青铜时代，出海捕鱼收获更多）、木栅栏（青铜时代，围住农田挡兔子、挡野兽）、瞭望塔（铁器时代，狼来了提早报警，还会放箭射狼）。
- **职业与技能**：每人有狩猎、种田、手艺、捕鱼四项本事，最拿手的就是职业（猎人、农夫、工匠、渔夫），分学徒、熟练、精通、大师。越干越熟练，孩子会从父母和长辈那里学，老人去世时手艺会传给后人。
- **心声与生平**：观察某人时按确认，可以看到他此刻在想什么，以及一生中最近的几件大事（出生、结伴、生子、盖房、受伤、成为大师、送别亲人……）。再按确认返回。
- 施放神力时，地图最上沿会有一条细横条提示，不挡画面。

## 自由意愿：岛民自己找事做

- 每个人除了饱食、体力、心情，还有**娱乐**和**社交**两项需求，会随时间下降。太无聊、太孤单都会让人不开心。
- 活干完了，他们会按自己的需求、性格、季节和时辰挑一件事做：夏天下海**游泳**，白天去沙滩**散步**，晌午在树下**打盹**，傍晚围着篝火**跳舞**、晚上出门**看星星**，春夏摘一朵**野花送给心上人**（送着送着可能就成了伴侣），和伴侣**约会**，冬天**打雪仗**，长老在篝火边**讲故事**，孩子们跑去听，还能学到长老的本事；孩子们白天**追着玩**。
- 勤快的人闲下来也会多囤点粮和柴；懒散的人更爱歇着；勇敢的人爱游泳，胆小的人不太下水。
- 心声与生平页多了一行**心愿**（比如"去海里游泳""遇到心上人""成为捕鱼大师"）和娱乐、社交两条进度条。

## 更聪明的岛民

- **救火**：火烧到村子附近（营地 8 格内，或房屋、粮仓、牧场旁边）时，勇敢、身体好的大人会从水边或井边打水去泼，一桶水能浇灭几处火苗，最多六个人一起救。测试里，大风天在村边点一把火，有人救火时烧掉的地少了约两成，烧毁的房子从 18 间降到 13 间。火烧成一片火海（40 处以上）就只能逃了。
- **未雨绸缪**：秋天会多囤粮（人均 12 份）、多备柴（25 根）过冬。
- **分工**：同一样活已经有一半人在干，其他人就去干别的；砍柴、采石最多两个人同时干。
- **结伴打猎**：有人在追野猪，猎人和勇敢的人会过去帮忙，每多一个帮手成功率高 25%，受伤的机会减半，猎物大家分。
- **灾后重建**：主动清理废墟（得到一点木材），再修房盖房。
- **照顾老弱**：生病或年老、躺在屋里的人饿了，家人和善良的人会送饭过去。

## 人情：恩怨、仪式、梦想

- **吵架与和好**：聊天时心情差、勤快和懒散的人凑一起、旧怨没消，都容易吵起来（善良的人能忍）。正在气头上的人互不搭理；怨气每天慢慢消，善良的人会主动去找对方和好。有人结了婚，暗暗喜欢其中一位的单身者会吃醋。
- **婚礼**：结为伴侣后，全岛聚到篝火边办婚礼，新人戴花冠。
- **葬礼与墓园**：有人去世，坟墓会集中在墓园里，大家去送行。
- **新年**：每年开春那天傍晚，大家围着篝火守岁，天上放烟花。
- **成人礼与梦想**：16 岁长大成人，许下一生的梦想：成为大师、住上最好的房子、儿孙满堂、钓到传说中的大鱼、出海看看远方、活到七十岁、亲眼见到神迹、交三个知心朋友。实现了会记进生平。心声页的"心愿"和"梦想"轮流显示。

## 岛外的世界

- **商船**：每隔十几天会有商船靠岸，停大半天。岛民拿多余的粮、木、石去换：良种（庄稼长得快）、好工具（干活快一成）、牲畜（能修牧场）、草药（病好得快一倍）、书简（孩子长本事）、一只小狗。
- **航海时代**：铁器之后的第四个时代。要有码头、和商船做过买卖、有人手艺或捕鱼够好。之后岛民会在码头边造一艘大船，每隔一阵子派两个人出海远航四到八天，回来时带回满舱的货物、远方的见闻，有时还带回一位新朋友。出海的人不在岛上，灾祸碰不到他们。
- **牧场与看家狗**：有了牲畜（或到了铁器时代）会修牧场，猪每天产一点粮食，春夏会下崽；缺粮时会宰一头。猎人偶尔会捡回狼崽养成看家狗，狗跟着主人，狼靠近就扑上去咬。

## 神的目标

- **成就**：选"观察 · 岛屿纪事"，再按确认就是成就页，共 24 项（上下翻页），比如十代传承、大师云集、十年太平、救火英雄、传说大鱼、梦想成真、灭绝后重生。
- **神像**：铁器时代以后，信仰到 60、岛上至少 5 人，岛民会花很大力气为你立一座金色神像。神像落成后信仰不会再掉到 60 以下，岛民会去神像前祈祷。
- **天象**（"天气"类里）：流星雨、彩虹、日食。不伤人，岛民都会跑出来看，心情大好，信仰上升；日食让他们又敬又怕。看见天象也算"亲眼见到神迹"。

## 画面

- 白天：海鸥飞过、春夏花丛边有蝴蝶、鱼跃出海面、海面粼光、云影慢慢飘过。
- 晨昏：日出日落时整座岛染上一层橘红。
- 夜里：有人在家的屋子窗口透出暖光，瞭望塔、神像、商船都亮着灯；夏夜有萤火虫。
- 新的东西都有自己的样子：牧场里拱来拱去的猪、看家狗、金色神像、商船和大船、救火时的水花、吵架时头顶冒火、婚礼的花冠。

## 复原大地

"祝福 · 复原大地"一键清掉灾害留下的一切：岩浆、火山口的山、碎石、神造的湖、焦土、废墟、灰烬变回草地或树苗，火灭、洪水退、恶狼消失、瘟疫痊愈、天放晴。岛上原有的山、房屋和人不受影响。

## 人口与石头

- 岛上最多 **8 个人**。怀着的孩子也占一个名额，满了就不再生。人口降到 4 人以下时，偶尔会有漂流者上岸，而且是岛上缺的那个性别。
- 成年人画成 10×14 像素（大头、腮红），孩子 8×11；树和房屋也相应放大了一点，人仍然是画面里最显眼的。
- **碎石**：地震裂缝、火山冷却、"创造矿石"留下的都是碎石（比山小、零散的灰石块）。碎石每天有一成机会风化回草地，岛民也会主动去凿开搬走（顺便得到石料）。岛上原有的山不会消失。

## 人类灭绝之后

- 最后一个人死去时，菜单会自动跳到"创造 · 降下先民"，按一下确认就有五位新的先民登岛（男女都有），正在肆虐的灾祸同时平息，仓库里留一点粮食和木柴。地貌、废墟和墓碑都保留。
- 想连岛一起换掉：选"设置 · 重造新岛"，按两次确认（4 秒内）。整座岛、所有人和家谱都会清空。

## 恶狼

- "创造 · 放出恶狼"放出五头黑毛红眼的恶狼，专门追着人咬，咬死为止。它们进不了屋，也不敢靠近点着的篝火三格之内。
- 岛民的反应：勇敢的成年人会提着家伙去打狼（一半多的机会打死，否则挨咬）；其他人躲在家里或篝火边，饿到不行才出门。
- 凶性持续 8 天，之后变回普通的狼。
- "祝福 · 消灭狼群"用天雷把岛上所有的狼劈死。

## 岛民的祈求

岛民遇到难处会向你祈求：缺粮时求食物，有人伤病时求治愈，灾祸当头时求平息，狼来了求驱赶，没柴烧时求木柴。底部面板会用粉色显示他们在求什么、还等多久（一天半）。

- 回应了（施放对应的神力）：信仰大涨，全岛欢呼。
- 没回应：信仰下降。难处自己过去了则不算。

## 岛上的其他新鲜事

- **丰收庆典**：粮食富余的傍晚，岛民会围着篝火庆祝，最多每 30 天一次。
- **漂流者**：人口不满时，偶尔有人被海浪冲上岸，在岛上安家。

## 放下不管的时候

- **息屏**：2 分钟没按键，屏幕熄灭，岛屿照常运行。
- **休眠**：10 分钟没按键，自动存档并进入深度休眠。按任意键唤醒。
- **离线推进**：从休眠中醒来时，按离开的时长补算（离线时 1 分钟 = 1 天，比在线的 1 倍速快一倍；最多补 24 小时即 1440 天）。补算时画面快进，可以按确认跳过。
- **归来纪事**：补算完显示一页总结：离开了多久、岛上过了多少天、新生、去世、结伴、新盖房屋、最近送别了谁。
- 暂停状态下休眠，岛上的时间不会走。
- 用电源键彻底关机后再开机，设备不知道关了多久，**不会补算**。想让岛屿在你不在时继续运行，就让它自己休眠，不要关机。

## 声音与声控

- **音效**：新生儿、有人去世、结为伴侣、立起祭石、施放创造和祝福类神力、打雷、地震和火山、起火、狼来了，各有一段短音。可在"设置 · 音效"里关闭。
- **声控神力**（默认关闭，在"设置 · 声控神力"里打开，顶栏会出现麦克风图标）：拍一下手，降下一道雷火；对着设备持续吹气约 0.7 秒，刮起大风。触发后 5 秒内不再响应。息屏时不监听。

## 岛民对神的态度

岛民看得见你做了什么。雪中送炭（他们挨饿时赐食物、有人受伤时治愈、灾害当头时平息）最得人心；降灾让他们恐惧。

- **信仰**高了，岛民会在营地边垒一块祭石，闲时去祈祷；心情更好，更愿意生孩子，干活更勤快。有祭石在，信仰不会低于三成。
- **恐惧**高了，岛民心情低落，不敢要孩子，白天躲在家里发抖，胆小的人尤其如此。恐惧远远压过信仰时，他们会推倒祭石。
- 两者都会随时间淡去。在"观察 · 岛屿纪事"里能看到当前的信仰和恐惧。

## 已验证 / 尚未验证

已在主机上验证（gcc + clang）：

- **长跑**：30 个随机种子各无人干预运行 400 天，30 座岛全部有人存活，400 天时人口 10～16（平均 14.7），传到了第四至第六代。平均每座岛 9 次庆典、2 位漂流者、6 次祈求。
- **灾害威力**（20 座岛、共 287 人，各施放一次，5 天内的死亡）：洪水 27%，火山 25%，瘟疫 16%，恶狼一群 12%（两群 22%），地震 10%，天降雷火约每次 0.7 人，暴风雪 1%（但所有人奄奄一息、木柴烧光），森林大火几乎不死人（但成树从 1333 棵烧到 97 棵）。没有一座岛因单次灾害灭绝。
- **新互动**：赐福和降罚、祈求得到回应后信仰从 20 升到 52、放狼与灭狼、灭绝后一键降下先民、重造新岛的两次确认，都有测试。
- **时间**：1 倍速下 120 秒正好过一天。
- **离线推进**：离开 9 小时补算 540 天，结果与一直开机逐步运行逐字节相同；离开 100 小时封顶在 1440 天；中途可跳过；暂停时和离开不到 1 分钟时不推进。
- **息屏与休眠**：120 秒息屏、600 秒请求休眠；唤醒的那一下按键不触发操作。
- **家谱**：10 座岛跑 400 天后，在世的人全部在册，父母与子女的记录两边对得上。
- **音效**：9 段音效长度 35～1400 毫秒，幅度不超限。
- **麦克风识别**（合成信号）：安静、类似说话的声音、持续的 1 kHz 音、持续的嘶嘶声、设备自己播放的雷声都不触发；一次拍手识别为拍手；1.2 秒低频气流声识别为吹气。
- **信仰与恐惧**：挨饿时赐三次食物，信仰从 0 升到 36 并立起祭石；连放火山、瘟疫、地震，恐惧升到 75，十天内祭石被毁。
- **存档**：整块读回后逐字节一致，读档后继续运行与不存档直接运行结果相同。
- **压力**：30 轮随机按键（会随机触发全部 37 项神力，包括重造新岛）、随机麦克风事件、随机帧间隔，各 2 万帧，开 ASan/UBSan，无越界、无非法状态。
- `main.c` 用一组仿造的头文件做过语法检查，只能说明没有笔误，不能说明接口用对了。

**真机情况：** 上一版已经用 GitHub Actions 编译通过并刷进设备，能正常游玩。这一版的改动（见上）还没有上机。下面这些仍然需要在真机上确认：

1. 新版本刷入后旧存档作废，会生成一座新岛。
2. **内存**：三块帧缓冲共 153.6 KB，加上模拟状态和家谱约 13 KB，都是静态内存；另有音频任务和编解码器。看启动日志里的 `free heap`。
3. **帧率**：目标 10 帧/秒，整张地图每帧重刷。
4. 颜色是否正常（RGB565 字节序由 BSP 的刷屏回调处理）。
5. 三个按键的单击、双击、长按是否按预期触发。
6. **存档**：现在是两块，世界 3.0 KB、家谱 2.8 KB，官方默认的 NVS 分区只有 24 KB。按估算放得下，要确认断电重启后岛屿和家谱都能恢复。
7. **深度休眠**：能否睡下去、按键能否唤醒、醒来后时间是否接得上（依赖系统时间在深度休眠期间由 RTC 维持，这是 ESP-IDF 的默认行为）。休眠时的实际电流没法在这里测。
8. **补算速度**：按主机上的速度折算，540 天大约需要十几秒，这是估计值。
9. **音效**：音量是否合适、有没有爆音。我听不到它们实际的声音。
10. **声控**：识别阈值是按合成信号定的，真实麦克风的灵敏度和设备外壳的影响都不知道。很可能需要调 `sfx.c` 里 `mic_block` 的几个数；所以它默认关闭。
